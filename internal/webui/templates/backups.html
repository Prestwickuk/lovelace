1. Download Local Portable Backup (.zip)

Exports a consistent point-in-time snapshot of your properties, accommodation, rates, reservations, guest CRM records, maintenance logs, and uploaded attachments, plus a manifest.json with per-file SHA-256 checksums. Active session tokens, recovery code hashes, password hashes, and server encryption keys are automatically excluded.

When provided, seals the .zip with Argon2id + AES-256-GCM (.zip.enc).

2. Cloud Bucket Destinations (AWS S3 · Cloudflare R2 · Google Cloud · Azure Blob)

Configure off-site cloud buckets for one-click or scheduled automatic backups with automatic retention pruning. Cloud credentials are encrypted at rest with AES-256-GCM and never displayed in plaintext.
